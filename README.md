# 🐾 AMIGO PET - Landing Page

Landing page da **AMIGO PET**, empresa fictícia de adestramento e educação canina, desenvolvida com **HTML5** e **CSS3** puros a partir do modelo visual entregue pelo cliente (`modelo.pdf`).

> 🚧 **Status:** em desenvolvimento.

## ✨ Seções da página

- **Cabeçalho** com logotipo em duas cores, menu de navegação e botão de agendamento
- **Banner (hero)** com chamada principal e foto
- **Serviços** em três cartões
- **Sobre** a empresa
- **Diferenciais** em faixa verde-clara
- **Depoimentos** (fictícios)
- **Contato** com formulário demonstrativo
- **Rodapé** com redes sociais

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (variáveis, Flexbox, Grid e media queries)
- Fonte [Poppins](https://fonts.google.com/specimen/Poppins) (Google Fonts)

## 📁 Estrutura

```text
├── index.html        ← estrutura e textos da página
├── css/
│   ├── base.css      ← base neutra (não editar)
│   └── style.css     ← estilos da landing page
├── img/              ← imagens do site
├── modelo.pdf        ← referência visual do cliente
└── INSTRUCOES.md     ← enunciado original da atividade
```

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```
2. Abra a pasta no **VS Code**.
3. Com a extensão **Live Server**, clique com o botão direito em `index.html` → **Open with Live Server**.

Também é possível abrir o `index.html` diretamente no navegador.

## 📱 Responsividade

A página possui ajustes para telas de até **980px** (tablets) e **700px** (celulares).

## 📝 Observações

- Os depoimentos são **fictícios**.
- O formulário de contato é **apenas demonstrativo** (sem back-end nesta etapa).
- Projeto desenvolvido como atividade prática de HTML e CSS — enunciado completo em [`INSTRUCOES.md`](INSTRUCOES.md).
